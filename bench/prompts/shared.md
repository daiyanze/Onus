This repository has no remote and no GitHub. GitHub is simulated with files:

- An issue is a file in `issues/`. Its labels are on its `Labels:` line.
- A pull request is a branch plus a `PULL_REQUEST.md` file at the root of
  that branch, holding the PR title and description. Commit it on the branch.
- A review is a `REVIEW.md` file at the root of the repository.
- Where a procedure says to use `gh`, push, wait for CI or post a comment, do
  the file version of it instead, or skip it when there is none. Do not ask
  whether to continue: nobody will answer. Finish the task in this session.
